实时演示

输入即生成，零延迟体验

无需离开键盘，无需记忆快捷键，只需输入前缀 + 中文名称，emoji 瞬间出现。

📝

空白区插入

在空白区域输入前缀 + emoji 名称，回车即可生成：

000龙 → 🐉
000火箭 → 🚀
000爱心 → ❤️
✏️

内容区插入

在已有内容中，输入前缀 + 名称后加空格即可替换：

今天天气真不错 000太阳 → 今天天气真不错 ☀️
加油 000火 → 加油 🔥

使用指南

三步上手，简单到不需要教程

1

安装插件

在 VS Code 扩展市场搜索「快捷 emoji」或「fast-emoji」，点击安装即可。

ext install stack-stark-code.fast-emoji
2

输入前缀 + 名称

在编辑器中输入默认前缀 000 加上 emoji 的中文名称。

000龙
3

Emoji 瞬间生成

空白区直接生成，内容区输入空格后自动替换，就是这么简单！

🐉
